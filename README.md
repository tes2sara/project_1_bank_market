# project_1_bank_market

The aim of this project is to build an end-to-end Microsoft Fabric solution that helps to identify which customers are most likely to convert or say yes to bank's products, using neural networks and interactive Power BI dashboard. 
Dataset citation: Moro, S., Rita, P., & Cortez, P. (2014). Bank Marketing [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306.
